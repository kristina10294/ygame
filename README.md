# ВЫХОД. Найди его вдвоём.

Кооперативная 3D escape-room для двоих игроков (Three.js + Node/Express).

## Что изменилось по сравнению с исходником

Исходный `index.html` использовал `window.storage` — API, доступное только
внутри артефактов Claude.ai. Для работы на обычном хостинге (Railway) это
заменено на маленький Express-сервер (`server.js`) с двумя эндпоинтами:

- `GET /api/kv/get?key=...` — прочитать значение
- `POST /api/kv/set` — записать значение `{ key, value }`

Клиентские функции `sGet`/`sSet` в `public/index.html` теперь ходят на эти
эндпоинты вместо `window.storage`. Логика игры (комнаты, синхронизация,
чат, пазлы) не менялась.

Хранилище — in-memory (`Map` в памяти процесса). Комнаты живут, пока жив
инстанс сервера — для одной игровой сессии этого достаточно. Записи старше
24 часов автоматически чистятся раз в час.

## Деплой на Railway

1. Залейте эту папку в GitHub-репозиторий (или используйте Railway CLI:
   `railway init` → `railway up` прямо из этой директории).
2. В Railway: New Project → Deploy from GitHub repo (или "Empty Project" +
   `railway up`).
3. Railway сам определит Node.js по `package.json` и запустит `npm start`.
4. Переменная `PORT` подставляется Railway автоматически — сервер уже её
   читает (`process.env.PORT`).
5. После деплоя откройте выданный Railway URL — это и есть ссылка, которую
   нужно дать обоим игрокам.

## Локальный запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000 в двух вкладках/браузерах, чтобы
протестировать вдвоём.
